# V1接线与供电计划

## 供电主线

```text
12V适配器中心正极
  → 2A保险丝
  → 两脚自锁总开关
  → +12V_SYS
      ├─ 三线CCT灯带公共正极
      └─ LM2596输入

LM2596输出5.0V → LD2410C等5V负载
NUCLEO调试阶段 → 先只由Mini-B USB供电
所有GND必须共地
```

灯带暖光负端和冷光负端分别进入两块LR7843的功率输出。PA8、PB6只接模块控制输入，不承载灯带电流。大电流路径使用0.5 mm²软线和端子，不进入面包板。

## 逻辑连接

| 模块 | 模块端 | NUCLEO | 说明 |
| --- | --- | --- | --- |
| LD2410C | TX | PA10 / USART1_RX | 交叉连接 |
| LD2410C | RX | PA9 / USART1_TX | 交叉连接 |
| BH1750 | SCL/SDA | PB8/PB9 | 3.3V供电起步 |
| SSD1306 | SCL/SDA | PB8/PB9 | 地址常见0x3C，以扫描结果为准 |
| SHT30 | SCL/SDA | PB8/PB9 | 地址以模块丝印/扫描为准 |
| DS3231 | SCL/SDA/SQW | PB8/PB9/PB1 | 使用3.3V；当前带CR2032板不得用5V充电 |
| EC11 | A/B/SW | PA6/PA7/PB0 | 3.3V供电，软件消抖 |
| LR7843暖/冷 | PWM | PA8/PB6 | 控制地与12V地共地 |
| 有源蜂鸣器 | SIG | PC0 | 若模块输入电流超GPIO能力，增加驱动管 |

## 首次上电硬性顺序

1. 不接任何模块，用万用表确认适配器极性和12V输出。
2. LM2596空载调到5.0V，断电后再接负载。
3. NUCLEO先只接USB；不要同时把外部5V与USB 5V硬并联。
4. 每次只接一个传感器，核对实物丝印后通电。
5. 灯带先截取约50 cm，单通道、低占空比测试，再加入第二通道。
