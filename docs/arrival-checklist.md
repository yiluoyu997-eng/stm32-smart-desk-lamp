# 硬件到货验收与单模块测试单

## 你负责提供的证据

- 每件模块正反面清晰照片，能看见型号和针脚丝印；
- 万用表测得的适配器电压、LM2596调整后的5.0V；
- 接线全景和端子近照；
- 串口输出、OLED显示或异常现象的视频/文字记录；
- 灯带测试长度、12V侧电流、MOS模块与铝槽温升。

## 我负责根据证据完成

- 对照实物修订针脚和供电表；
- 生成/修改Keil工程、驱动和测试固件；
- 分析日志和异常，给出下一步接线或代码改动；
- 把通过项、失败项和测量值写入测试报告并更新GitHub。

## 到货测试顺序与通过标准

| 顺序 | 对象 | 通过标准 |
| ---: | --- | --- |
| 1 | NUCLEO-F411RE | Keil能识别ST-LINK；可下载；板载LED和115200串口持续运行 |
| 2 | BH1750 | 亮/暗遮挡时数值方向正确；拔线后在规定超时内报告故障 |
| 3 | LD2410C | 能区分有人/无人；拔掉UART后状态变UNKNOWN，不误启动关灯计时 |
| 4 | EC11 + OLED | 正反转、按压各触发一次；OLED无明显花屏且能显示故障状态 |
| 5 | 单路PWM | 0/10/50/100%指令稳定；模块不过热；没有肉眼明显闪烁 |
| 6 | 双路PWM | 暖/冷通道不串扰；总亮度限制有效；测量12V侧最大电流 |
| 7 | RTC/SHT30/蜂鸣器 | 时间掉电保持；温湿度数据合理；蜂鸣器可开关 |
| 8 | 核心联调 | 自动/手动、迟滞、无人120s、故障冻结、恢复3帧全部有记录 |

任何单模块未通过时不继续叠加模块，先保留失败接线、日志和测量结果。
